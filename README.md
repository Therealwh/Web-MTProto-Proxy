# ⚡️ Web MTProto прокси для Telegram

Рабочие Web MTProto-серверы с автопроверкой. Трафик маскируется под обычный HTTPS — подключение живёт дольше, чем у классических прокси.

## 🤖 Подключение за 60 секунд

| Бот | Что делает |
|---|---|
| [**@webproxy_tgrobot**](https://t.me/webproxy_tgrobot) | 🆓 Бесплатный Web MTProto-прокси: свежий сервер за пару секунд, без регистрации |
| [**@webproxy_panel_bot**](https://t.me/webproxy_panel_bot) | 💎 Премиум: личный выделенный канал 24/7, скорость без лимитов |

**Как подключить:** откройте бота → нажмите «Подключить» → Telegram сам добавит сервер. Всё.

## 📋 Свежие списки прокси

- [web-proxies.txt](web-proxies.txt) — только Web MTProto (tg://webproxy)
- [proxies.txt](proxies.txt) — все проверенные серверы (tg://proxy)

Списки обновляются автоматически, мёртвые серверы удаляются.
